# NT521 Lab 2 — Web application target

Synthetic Flask + SQLite app for local security review only.
Do **not** deploy to the public internet.

## Run (Ubuntu)

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000
